# OnlinePBX Analytics Dashboard

## Описание проекта
Проект представляет собой систему аналитики телефонии, построенную на базе OnlinePBX API, Python, BigQuery и SQL.

Цель проекта - автоматизировать сбор, хранение, обработку и визуализацию данных по звонкам для анализа эффективности менеджеров и контроля KPI телефонии.

---

## Основной функционал

### Сбор данных
Реализован автоматический сбор данных из OnlinePBX API:
- история звонков,
- данные менеджеров,
- webhook-события в реальном времени.

### ETL-процессы
Разработаны ETL-скрипты на Python для:
- получения данных через REST API,
- очистки и преобразования данных,
- подготовки аналитических таблиц,
- загрузки данных в Google BigQuery.

### SQL-аналитика
Созданы SQL-витрины и представления для:
- агрегации звонков,
- расчета KPI,
- анализа эффективности менеджеров,
- построения dashboard.

### Dashboard
Разработан интерактивный dashboard с:
- фильтрацией по менеджерам,
- фильтрацией по датам,
- анализом звонков по часам,
- анализом эффективности сотрудников,
- KPI телефонии.
